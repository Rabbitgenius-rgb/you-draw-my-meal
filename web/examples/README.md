# 原创三联示例

用户主动确认后才导入；默认私密、非 MCP 数据、不进入真实门店菜单。`original-trio.json` 包含：

- 霸！：作者获准公开的 8 条原笔迹，授权范围见 [NOTICE](../../NOTICE.md)。
- 薯条开花、可乐起飞：本次新创作的代码原生笔迹，MIT。
- 今天这桌，有点想象力：一份使用明确版本引用的餐纸方案。

仅使用独立演示 ID 和示例快照，未附真实历史、草稿、品牌摄影或嵌入图片。重复导入会去重。未配置 Token 时也可体验画册、版式及导出；真实查询能力须用户另行配置 MCP。

重建命令：`npm run examples:build`。生成器仅从 [ba-strokes.json](ba-strokes.json) 读取获准公开的笔迹，另外两幅直接由[源代码](../../scripts/make-public-examples.js)生成。源数据和生成文件使用稳定 ID、固定示例日期和内容哈希，可重复生成；不会读取私人备份或浏览器。
