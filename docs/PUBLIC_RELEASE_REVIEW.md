## 检查方法

- 用精确文件允许清单复制源码；不递归复制原工作目录、参考图或 artifacts。
- 扫描候选文件中的常见凭证格式、私钥、JWT、硬编码 Bearer、私人路径、不应公开的文件名与旧参考作品标记，输出只包含规则及文件路径，不打印疑似值。
- 不读取实际 `.env.local`、设备凭据或浏览器私人存储。该检查能定位已覆盖的模式，不能证明任意格式秘密不存在。
- 所有非文本文件均来自项目通用食物插画或本次实际演示截图；逐项查看内容、检查图片元数据，不用文本扫描代替图片检查。
- 逐项核对锁文件与安装包许可文件，保存原文、来源、版本及完整性摘要。
- 公开示例没有嵌入图片、草稿、真实菜单或旧存储归档；霸原笔迹与选取的原始种子按内容哈希核对。
- 在不含凭证的临时副本独立安装，运行检查、测试、示例重建；实际浏览器验证主动导入、重复去重、三版式及 PNG 下载。
- 对最终分发清单逐文件计算 SHA-256；ZIP 按清单创建，核对条目、CRC 和解压后内容，不打包依赖或生成的本机配置。
