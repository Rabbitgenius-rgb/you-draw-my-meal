# 数据与隐私

应用默认在本机运行，无用户账户和云端作品上传。画作、门店餐品快照、公开许可、餐纸、不可变版本和草稿保存在当前浏览器来源的 IndexedDB；多标签共享同一来源的数据，换端口、浏览器或设备则不共享。

“允许公开”控制当前浏览器内对应门店的展示，不会把作品传给麦当劳，也不向其他设备发布。没有分析统计 SDK、第三方字体脚本或广告。浏览器请求上游餐品 HTTPS 图时会连接图片地址；城市和地标查询经本机后端发送给麦当劳 MCP。外部服务适用各自规则。

MCP Token 由用户自行申请，仅交给本机后端；页面保存到 `.env.local` 时权限为 `600`。Token 不进入示例、整册备份、小程序包或公开候选文件。后端只监听 `127.0.0.1`，静态文件只允许 `web/` 和 `miniprogram/`；配置接口校验同源 Origin 和随机 nonce。

整册备份包含作品、素材、日期、门店餐品关联、版本、方案和未完成草稿。请自行保管，勿随源码、Issue、截图或录屏分享。导入新增作品默认私密，不继承公开展示授权；已有公开状态不被导入覆盖。

删除画册中的作品不会自动删除已保存餐纸引用的历史版本。为了让旧方案可用，这些副本仍保存在本机，并可能进入整册备份。需要彻底清除当前浏览器数据时，先保存需要的备份，再使用浏览器网站数据管理；该操作无法由本应用恢复。

当前服务是本机原型，不能直接把监听地址改为公网并当作多用户产品。公开源码不等于公开运行服务。本次候选整理不执行部署、账户授权或报名提交。
