# 录屏清单

当前只有[脚本](DEMO_SCRIPT.md)，尚未录制视频。

- [ ] 使用独立演示浏览器来源，主动导入本候选的三幅私密示例；不展示私人画册。
- [ ] 录制前配置 MCP，关闭配置面板、终端及开发者工具；通知和无关任务窗口不入镜。
- [ ] 真实门店/菜单查询成功并记录录制日期；不能用示例或测试夹具冒充。
- [ ] 单人保存、同设备双人隐藏答案、搜索和前后浏览操作可读。
- [ ] 仅对临时演示作品授权与撤回，说明本机画廊边界。
- [ ] 餐纸三版式、标题、放大与关闭、保存和实际下载均成功；清楚展示 PNG 格式。
- [ ] 不出现 Token、请求头、nonce、设备配置、个人备份或其他任务信息。
- [ ] 完整回放，检查字幕、窗口边缘、跳转及下载提示；失败动作如实处理。
- [ ] 用新视频与截图替换时，复核素材与授权范围，重做公开文件检查。
- [ ] 保存视频文件、录制日期与实际版本；完成后才勾选，不以脚本代替成品。
